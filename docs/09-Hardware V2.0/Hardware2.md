## Overview
One potential improvement in the hardware design for a future version could be to use a through hole mount shift register instead of surface mount. This would allow for easier testing and save time from being wasted on getting a surface mount component soldered. It would also make the shift register less likely to be burnt out before testing the code and wasting time on wondering why the code is not working when it turns out the shift register was burnt out all along. Another hardware design improvement would be to verify the size of components matches the footprint on the PCB before the PCB is manufactured. The footprint of the fuse did not match the actual size of the fuse purchased which made it not fit the mounting holes.

## Lessons Learned
I learned from this project that when designing a circuit board it takes lots of revisions to get a working version. I also learned that you should double check that component footprints match the physical dimensions of the component before manufacturing. Another lesson I learned is that when planning on manufacturing something like a PCB you should have a back up option incase the machine shop breaks down right before the due date.


## Recommendations for Future Students
Work on assignments early and ask the professor for help immediately if you are stuck. Plan to have your PCB ready to be milled a week before the actual assignment due date so you can switch with enough time to JLCPCB if the Peralta Lab mill breaks down again. Double check your component footprints match the physical dimensions of your parts. To have enough time to get all the lab assignments and project assignment done, work on the lab assignments a week before they are actually schdeuled. Go into Peralta Lab an hour before class starts so you can get your assignments done on time.
